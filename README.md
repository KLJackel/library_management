Library Management System (CLI)

A lightweight, terminal-based Library Management System built in Python. This program allows users to manage a collection of books, perform case-insensitive searches, and toggle book availability—utilizing Core Object-Oriented Programming (OOP) principles, lambda functions, and array/list manipulation.

Features

Inventory Display: View all books currently stored in the system alongside their indexing and availability status.

Add New Books: Expand the collection dynamically by providing book titles and author names.

Search Capabilities: Find books quickly using partial titles or author names using Python lambda expressions and filter().

Toggle Availability: Update whether a book is Available or Checked Out dynamically.

Interactive Terminal Menu: Simple command-line interface (CLI) event loop with input validation and error handling.
